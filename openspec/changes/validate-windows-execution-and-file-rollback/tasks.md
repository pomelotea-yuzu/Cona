- 本轮 E 系列结果：E01、E04、E05、E06、E09、E11、E12、E13、E14 通过；E07、E08 受阻（宿主接口与受控出口未实现）；E02、E03、E10、F01–F08、P02、P03 未测。
- 实测接口条件（只约束原型，不构成产品安全承诺）：
  - AppContainer 进程在环境块缺少 `USERPROFILE`、`APPDATA` 或 `LOCALAPPDATA` 之一时 `CreateProcess` 直接失败（`ERROR_ENVVAR_NOT_FOUND`）；原型把这三项指向容器自有目录，而不继承宿主 profile 路径。
  - 容器需要祖先目录遍历权限，而按路径逐段解析（Node 的 `realpathSync`）会触及卷根目录；卷根目录授权在未提升环境下被拒（rc=5），故文件型 Node 载荷以 `--preserve-symlinks-main` 启动仅作为原型绕行。该授权已记入 P01 的首次设置提升权限步骤。
  - AppContainer 会把 `LOCALAPPDATA` 与 `TEMP` 重定向到容器自有 package 目录，显式环境列表对此不完全权威；结论按实际值记录。
  - 容器身份在仓库目录上的授权由驱动在结束时回收并清扫历史遗留；本轮结束后 `D:\Cona` 与 `output` 上容器 SID 计数为 0。
- 保持未测／受阻、不以整体收益覆盖的能力：受控联网出口与绑定任务身份的窄宿主接口、模型资料发送测试网关、受限环境下的 pnpm／Git 实际工作、文件版本存储与交付回退、并发多任务一致性、安装与资源开销重复测量。
