## 已知的路线级事实（会影响结论）

1. **AppContainer 与 Git for Windows 不兼容**——容器内 Git 无法解析自身工作目录，命令全部 128。产品需安排
   "容器外可信 Git 服务"或接受 Git 不在隔离内。
2. **一次性提权不可回避**（卷根读属性／遍历 + 运行时只读授权），但日常运行不需要提权。
3. **产品默认可做到不主动碰 C 盘**，唯一例外是 Windows 自建的容器身份档案目录。

详见本机 `docs/engineering/reports/2026-10-18-validation-run-summary.md`（运行报告）与
本机 `docs/research/windows-isolation-primitives.md`（隔离原语实测）；两份文件均仅本机保留、不入库。
